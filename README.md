# 🧩 Sales Support CRM

> A modern, web-based **Customer Relationship Management (CRM)** system built with Laravel to streamline sales operations, manage leads, track customer interactions, and generate actionable insights — all from a unified dashboard.

🌐 **Live Demo:** https://crm.saitsolution.com.np

---

## 🚀 Overview

**Sales Support CRM** is designed to help businesses efficiently manage their sales pipeline — from lead acquisition to customer retention. It provides powerful tools for tracking interactions, automating follow-ups, and analyzing performance.

---

## ✨ Features

- 🔹 **Lead Management**  
  Capture, track, and convert leads through a structured sales funnel.

- 🔹 **Customer & Contact Management**  
  Maintain a centralized and organized database of customers.

- 🔹 **Task & Follow-up Tracking**  
  Never miss a deal with scheduled tasks and reminders.

- 🔹 **Invoice & Billing System**  
  Generate, manage, and track invoices directly within the CRM.

- 🔹 **Reports & Analytics**  
  Gain insights with visual dashboards and exportable reports.

- 🔹 **Role-Based Access Control (RBAC)**  
  Manage permissions for Admins, Managers, and Sales Representatives.

- 🔹 **Activity Logs**  
  Full audit trail of user activities and system interactions.

- 🔹 **Responsive UI**  
  Mobile-friendly interface built with Bootstrap & AdminLTE.

---

## 🛠 Tech Stack

| Layer       | Technology                         |
|------------|----------------------------------|
| Backend     | Laravel (PHP)                    |
| Frontend    | Blade, Bootstrap, AdminLTE       |
| Database    | MySQL / MariaDB                 |
| Authentication | Laravel Breeze / Sanctum     |
| Server      | Apache / Nginx                  |
| Package Manager | Composer, NPM              |

## 📦 Getting Started

### ✅ Prerequisites

Ensure your environment meets the following requirements:

- PHP >= 8.1  
- Composer  
- Node.js & NPM  
- MySQL >= 5.7 or MariaDB  
- Git
